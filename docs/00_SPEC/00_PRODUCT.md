# 00 — 제품 정의 · 범위

> 상태: **불변 계약**. CODEX 수정 금지.
> 이 문서의 "비범위"에 있는 것을 구현하면 하네스 위반이다.

---

## 1. 한 줄 정의

**AIDREAM** 은 AI로 제작된 드라마를 크리에이터가 업로드하고,
시청자가 팔로우·피드·플레이어로 소비하는 **영상 소셜 네트워크**다.

## 2. 범위 (이번 개발 대상)

| 영역 | 포함 내용 |
|---|---|
| 계정 | 이메일 회원가입/로그인, 소셜 로그인(Google), 프로필, 역할(VIEWER/CREATOR/MODERATOR/ADMIN) |
| 업로드 | 멀티파트 업로드, 진행률, 재개, 형식/용량 검증 |
| 트랜스코드 | ffmpeg 기반 HLS 변환(다중 화질), 썸네일·포스터 자동 추출, 재시도 |
| 작품 구조 | 시리즈 → (시즌) → 에피소드, 공개예약, 초안/공개/숨김 |
| 재생 | HLS 플레이어, 자동 화질, 이어보기, 조회수 집계 |
| 피드 | 팔로잉 피드 / 인기 피드 / 태그·검색, 커서 페이지네이션 |
| 소셜 | 팔로우, 좋아요, 댓글(1단 대댓글), 알림 |
| 신고·심사 | 신고 접수, 심사큐, 숨김/삭제 조치, 연령등급 |
| 운영 | 구조적 로깅, 메트릭, 알럿, 백업, 배포/롤백 |
| 플랫폼 | Next.js 웹 (데스크톱 + 모바일 웹 + PWA 설치) |

## 3. 비범위 (이번에 만들지 않는다)

| 제외 | 이유 / 시점 |
|---|---|
| **AI 영상 생성** | 채널이 외부 도구로 제작 → 업로드. 플랫폼은 유통만. |
| 라이브 스트리밍 | Phase 3 이후. |
| 결제 · 유료구독 · 정산 | Phase 3. 단, 도메인 모델에 확장 여지만 남긴다. |
| 네이티브 iOS/Android 앱 | **Phase 2** (`T13_PWA_PHASE2.md` 에서 API 안정화만 준비) |
| DM(1:1 메시지) | Phase 3. |
| 추천 ML 모델 | Phase 3. 이번엔 규칙 기반 `rankScore` 만. |
| 다국어 UI | ko 우선. i18n 구조만 잡고 문구는 ko 만 채운다. |
| 자체 CDN 구축 | Akamai CDN 사용. |
| GPU 서버 | 트랜스코드는 CPU ffmpeg. |

## 4. 사용자 역할

| 역할 | 할 수 있는 것 |
|---|---|
| `VIEWER` | 시청, 좋아요, 댓글, 팔로우, 신고 |
| `CREATOR` | VIEWER + 시리즈/에피소드 생성·업로드·공개 관리, 자기 통계 조회 |
| `MODERATOR` | VIEWER + 신고 심사, 콘텐츠 숨김, 계정 제한 |
| `ADMIN` | 전부 + 역할 부여, 시스템 설정 |

권한 매트릭스 상세: `07_AUTH_SECURITY.md` §권한

## 5. 핵심 사용자 스토리 (E2E 테스트의 근거)

| ID | 스토리 | 검증 태스크 |
|---|---|---|
| US-01 | 방문자가 이메일로 가입하고 로그인한다 | T03 |
| US-02 | 크리에이터가 시리즈를 만들고 1화를 업로드한다 | T05, T08 |
| US-03 | 업로드된 영상이 자동으로 HLS 변환되어 재생 가능해진다 | T06 |
| US-04 | 시청자가 에피소드를 끝까지 보고, 다음 접속 시 이어본다 | T07 |
| US-05 | 시청자가 크리에이터를 팔로우하면 팔로잉 피드에 신작이 뜬다 | T09, T10 |
| US-06 | 시청자가 좋아요·댓글을 남기고 크리에이터가 알림을 받는다 | T10 |
| US-07 | 시청자가 부적절한 에피소드를 신고하고 모더레이터가 숨긴다 | T12 |
| US-08 | 크리에이터가 공개예약한 에피소드가 예정 시각에 공개된다 | T08 |
| US-09 | 대용량 업로드 중 네트워크가 끊겨도 재개할 수 있다 | T05 |
| US-10 | 트랜스코드 실패 시 크리에이터가 원인을 보고 재시도한다 | T06 |

**규칙**: 위 10개는 `apps/web/e2e/` 에 각각 1개 이상의 Playwright 시나리오로 존재해야 한다.
US 번호를 테스트 제목에 넣는다. 예: `test('US-03 업로드 후 HLS 재생 가능', ...)`

## 6. 콘텐츠 정책 (제품 제약)

| 항목 | 값 |
|---|---|
| 1개 파일 최대 용량 | **티어별** — `11_CAPACITY_TIERS.md` §3 (현재 T0: **2 GB**) |
| 1개 에피소드 최대 길이 | **티어별** — 현재 T0: **20분** |
| 허용 컨테이너 | `.mp4`, `.mov`, `.mkv`, `.webm` |
| 허용 비디오 코덱 | H.264, H.265/HEVC, VP9, AV1 |
| 허용 오디오 코덱 | AAC, MP3, Opus, FLAC |
| 최소 해상도 | 640×360 |
| AI 제작 표기 | **필수**. 업로드 시 사용 도구/모델 기재란 필수 입력. |
| 연령등급 | 업로더가 선언, 모더레이터가 조정 가능 |
| 저작권 | 업로더 책임 선언 체크 필수. 신고 시 즉시 숨김 후 심사. |

**AI 제작 표기 필수**는 법적/신뢰 요건이며 비즈니스 로직에 강제된다.
`Episode.aiDisclosure` 가 비어 있으면 `PUBLISHED` 로 전이 불가. (T08 상태기계)

## 7. 성공 판정 (제품 관점 DoD)

- US-01 ~ US-10 전부 E2E 통과

- 배포 후 롤백 1회 성공 시연 — `20_OPS/O01_DEPLOY.md`
