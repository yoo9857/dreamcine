# 가입 프로필·동의 수집

## 수집 항목

| 항목 | 필수 | 저장 위치 | 목적 |
| --- | --- | --- | --- |
| 이메일 확인 입력 | 예 | 저장하지 않음 | 이메일 오입력 방지 |
| 생년월일 | 예 | `User.birthDate` | 연령 계산과 시청 등급 적용 |
| 성별 | 예 | `User.gender` | 서비스 분석; `응답하지 않음` 제공 |
| 이용 목적 | 예 | `User.signupPurpose` | 시청자·크리에이터·복합 사용자 구분 |
| 국가 | 예 | `User.country` | 한국·미국·중국·일본 시장 구분 |
| 약관·개인정보 동의 | 예 | `UserConsent` | 가입 계약과 개인정보 처리 근거 |
| 마케팅 수신 동의 | 아니요 | `UserConsent` | 이벤트 메일 발송 가능 여부 |

나이는 시간이 지나면 변하므로 숫자 나이를 저장하지 않고 생년월일에서 계산한다.
크리에이터 선택은 가입 목적 데이터이며 `User.role` 권한을 자동으로 올리지 않는다.

## 동의 정책

- 약관 및 개인정보 동의가 없으면 가입 요청을 거절한다.
- 마케팅 수신은 기본값을 `false`로 두며 동의하지 않아도 가입할 수 있다.
- 동의 종류, 문서 버전, 허용 여부를 `UserConsent`에 가입 계정과 함께 저장한다.
- 이벤트 메일 발송 전 최신 `MARKETING` 동의가 유효한지 다시 확인해야 한다.
- 약관과 개인정보 처리방침의 실제 문서는 출시 전 법률 검토와 버전 고정이 필요하다.

## 운영 연결

- 공개 문서 경로는 `/terms`, `/privacy`이며 가입 체크박스에서 새 창으로 확인한다.
- `/account#consents`에서 현재 동의 상태를 확인하고 마케팅 동의를 즉시 변경한다.
- 메일 수신거부는 90일 유효 HMAC 토큰을 사용한다. GET은 확인 화면만 열고 POST에서
  철회하므로 메일 보안 스캐너의 링크 조회가 곧바로 철회로 이어지지 않는다.
- 마케팅 후보 조회는 활성·이메일 인증·현재 문서 버전 동의 계정만 반환하며,
  SMTP 발송 직전에도 최신 동의를 재확인한다.
- A19 판정은 클라이언트가 보낸 출생연도를 사용하지 않고 `User.birthDate`를 서버에서
  다시 조회하여 만 19번째 생일이 지났는지 판정한다.

필수 약관·개인정보 동의의 철회는 서비스 계약 종료와 개인정보 삭제 절차가 함께
필요하므로 현재 화면에서는 개인정보 담당자 접수 경로를 제공한다. 자동 계정 삭제와
유예 후 파기 작업은 별도 계정 탈퇴 작업지시서에서 완성한다.
