## 3. 화면별 상태 계약 (★ 모든 화면이 4개 상태를 전부 가진다)

**철칙**: 모든 데이터 화면은 **로딩 / 비어있음 / 오류 / 정상** 4개 상태를 구현한다.
하나라도 빠지면 미완성이다. 특히 **비어있음과 오류를 빼먹지 말 것.**

| 화면 | 로딩 | 비어있음 | 오류 |
|---|---|---|---|
| 피드 | 스켈레톤 카드 8개 | "아직 작품이 없습니다" + 인기 피드로 이동 버튼 | 재시도 버튼 + 에러코드 표시 |
| 팔로잉 피드 | 스켈레톤 | "팔로우한 크리에이터가 없습니다" + 추천 목록 | 재시도 |
| 시리즈 상세 | 스켈레톤 | "공개된 에피소드가 없습니다" | 재시도 |
| 플레이어 | 포스터 + 스피너 | — | 재생 실패 안내 + 새로고침 (에러코드 표시) |
| 댓글 | 스켈레톤 3개 | "첫 댓글을 남겨보세요" | 재시도 |
| 검색 | 스피너 | "검색 결과가 없습니다" + 인기 태그 | 재시도 |
| 알림 | 스켈레톤 | "새 알림이 없습니다" | 재시도 |
| 업로드 | 진행률 바 | — | 실패 원인 + 재개/재시도 버튼 |
| 스튜디오 목록 | 스켈레톤 | "첫 시리즈를 만들어보세요" + CTA | 재시도 |
| 심사큐 | 스켈레톤 | "처리할 신고가 없습니다" | 재시도 |

## 4. 업로드 화면 상태 기계 (T05 — 가장 복잡한 UI)

```
[대기] ─파일선택─▶ [검증중] ─통과─▶ [세션생성중] ─▶ [업로드중] ─▶ [완료처리중]
                      │                  │              │              │
                      └─실패─▶[오류]      └─실패─▶[오류]   ├─일시정지─▶[정지]│
                                                        │       ▲       │
                                                        │       └─재개───┘
                                                        └─네트워크단절─▶[재개가능]
                                                                          │
[완료처리중] ─▶ [변환중 (진행률 폴링)] ─▶ [준비완료] ─▶ 에피소드 정보 입력
                        │
                        └─실패─▶ [변환실패] (원인 표시 + 재시도 버튼)
```

| 상태 | 화면에 보여야 하는 것 |
|---|---|
| 업로드중 | 파트 진행률 %, 전송량/총량, 예상 남은 시간, **일시정지 버튼** |
| 정지 / 재개가능 | 재개 버튼, "이어서 올릴 수 있습니다" 안내 |
| 변환중 | 진행률 %, "창을 닫아도 계속 진행됩니다" 안내 |
| 변환실패 | 사용자 언어로 된 원인 (에러코드 매핑) + 재시도 버튼 (attemptCount < 3 일 때만) |

**필수 UX**: 업로드 중 페이지 이탈 시 `beforeunload` 경고.
단, **변환중에는 경고하지 않는다** (서버에서 계속 진행되므로).

**재개 구현**: `uploadId` 를 `localStorage` 에 저장.
업로드 화면 재진입 시 미완료 세션을 감지해 "이어서 올리기" 를 제안한다.

## 5. 플레이어 요구사항 (T07)

| 기능 | 필수 | 비고 |
|---|---|---|
| 재생/일시정지 | ○ | 스페이스바 |
| 시크바 | ○ | 드래그 + 클릭. 프리뷰 스프라이트 표시 |
| 볼륨 | ○ | 값 `localStorage` 저장 |
| 전체화면 | ○ | F 키 |
| 화질 선택 | ○ | 자동 + 수동. 현재 화질 표시 |
| 재생속도 | ○ | 0.5 ~ 2.0 |
| 이어보기 | ○ | 진입 시 "n분부터 이어보기" 토스트 + 처음부터 버튼 |
| 다음화 | ○ | 종료 10초 전 카드 노출 |
| 키보드 | ○ | `←/→` 10초, `↑/↓` 볼륨, `M` 음소거, `F` 전체화면 |
| 자막 | ✗ | Phase 3 |
| PiP | ○ | 브라우저 기본 API |

**접근성 필수**: 모든 컨트롤에 `aria-label`, 포커스 링 유지,
키보드만으로 전체 조작 가능. 자동재생은 음소거 상태에서만.

## 10. 문구 규칙

| 규칙 | 내용 |
|---|---|
| 언어 | 한국어. `apps/web/src/lib/messages/ko.ts` 에 집중 |
| 구조 | i18n 구조는 잡되 `ko` 만 채운다 (`00_PRODUCT.md` 비범위) |
| 에러 문구 | `error-messages.ts` (`09_ERROR_CATALOG.md` §5). 코드→문구 1:1 |
| 톤 | 존댓말. 사용자를 탓하지 않는다. 다음 행동을 제시한다. |
| 금지 | "오류가 발생했습니다" 만 표시하고 끝내는 것. 무엇을 할 수 있는지 항상 제시. |
