# 등록 화면 진행 안내 개선

사용자가 비활성 버튼을 고장으로 오해하고 아래 필수 입력을 발견하기 어려운 문제를 수정했다.

- 빈 단계에서도 버튼을 사용할 수 있다. 작품 선택하기·영상 업로드하기·영상 선택하기·제목 입력하기·AI 도구 선택하기로 다음 행동을 표시하고, 누르면 해당 입력 위치로 이동하며 안내한다. 저장 중에는 중복 조작을 잠근다.
- 새 시리즈는 하단 ‘만들고 다음’ 버튼 하나로 생성과 영상 준비 단계 이동을 연결한다. 기존 시리즈 생성 폼의 다른 사용처는 유지한다.
- 정보 입력 화면 위에 제목·AI 도구의 완료 여부와 바로가기를 제공한다. 남은 필수 항목을 상단 및 모바일 하단에 표시한다. 선택 사항은 별도 접기 영역으로 유지한다.
- 중복 소개와 단계 헤더 높이를 줄이고 PC 하단 버튼 영역의 고정을 제거했다. 모바일은 진행 안내를 포함한 고정 버튼과 충분한 하단 여백을 제공한다.
- 후속 요청: 중복 ‘대시보드로 돌아가기’ 링크와 CREATE 표시를 제거했다. 페이지 위쪽 여백과 제목 아래 간격도 줄여 등록 단계를 위로 당겼다. 스튜디오 내비게이션의 대시보드 링크는 유지한다.
- API·DB·권한·업로드 계약 변경 없음. 단계 왕복 시 입력·업로더 유지, 자동 저장 방지용 이동/제출 버튼 DOM 분리를 유지한다.

검증: 관련 Vitest 42개 통과. 실제 컴포넌트 브라우저에서 320·390·768·1024·1366·1440px의 세 단계, 입력 위치 이동, 가로 넘침, 모바일 버튼 위치, 제목·도구·영상 선택 보존, 단계 왕복 시 저장 요청 0건 확인. PC·모바일 화면 검수. TypeScript 및 정적 검사 적용. 임시 미리보기 라우트 제거.
