# 시리즈 등록 한 페이지 개선

사용자 요청: `/studio/new`에서 단계별 화면 이동 없이 시리즈·영상·정보를 선택하고 등록하도록 레이아웃과 기능을 개선한다.

## 변경

- 단계 내비게이션을 제거하고 시리즈 선택과 영상·상세 입력을 한 페이지에 표시한다. 데스크톱은 입력 영역과 고정 요약의 두 열, 태블릿·모바일은 한 열이다. 큰 카드 대신 얇은 테두리와 작은 상태 표시를 사용한다.
- 기존 시리즈는 최근 수정순으로 고르고, 7개 이상이면 검색한다. 새 시리즈는 형식·제목을 입력해 만들며 생성 후 같은 화면에서 선택된다. 새 시리즈 만들기로 전환하면 이전 등록 대상을 해제해 다른 작품에 잘못 저장하는 일을 막는다.
- 영상 업로드·준비된 영상 선택·장면 확인·제목·설명·시즌/회차·태그·등급·AI 제작 표기가 함께 보인다. 시리즈 선택을 바꿔도 영상 입력과 업로더를 유지한다.
- 우측 요약에 시리즈·영상·제목·AI 표기를 반영하고 준비된 항목 수를 표시한다. 필수 선택 후 한 번의 ‘초안으로 등록’으로 저장한다. 시리즈 생성과 영상 저장이 별도 동작이며 등록 즉시 공개되지 않는다는 안내를 제공한다.
- 저장 후 초안 완료 화면에서 공개, 관리, 다음 영상 등록으로 이어진다. 네트워크 오류 시 입력을 보존하고 전송 잠금을 해제한다. 즉시 제출 잠금과 응답 스키마 검증을 추가했다. 자동 POST 재전송은 하지 않는다.
- 기능 점검 중 공개 피드 조회가 visibility를 검사하지 않는 기존 결함을 발견했다. 최신·인기·팔로잉 모두 영상과 시리즈가 PUBLIC인 경우에만 노출하고 캐시 키를 v2로 바꿔 기존 응답을 재사용하지 않도록 했다. 스키마·마이그레이션 변경은 없다.

## 검증

- 관련 컴포넌트·피드 서비스·피드 repository 단위 검사. 최종 개수는 배포 인수인계에 기록한다.
- 실제 컴포넌트를 사용하는 임시 로컬 화면으로 320·390·768·1440px의 필수 선택, 버튼 활성화, 가로 넘침 및 페이지 오류 없음 확인. 스크린샷으로 데스크톱·모바일 배치와 대비를 확인했다. 임시 라우트는 검사 후 삭제했으며 운영 인증 경계는 변경하지 않았다.
- 업로드 변환 파이프라인은 변경하지 않았다. 이 브라우저 검사는 파일 전송·트랜스코딩 완료 검사를 의미하지 않는다.
- O01 Fast lane으로 웹 이미지만 배포한다. 전체 DB·Lighthouse 게이트 통과를 의미하지 않는다. 운영 SHA와 배포 후 검증은 `docs/HANDOFF.md` 최상단에 기록한다.
