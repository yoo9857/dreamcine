# 댓글 작성·답글·관리 개선

사용자 요청: 댓글 등록을 포함한 기능과 UI/UX 개선.

## 변경

- 큰 카드 테두리 대신 아바타·작성자·작성일·본문·작은 동작 버튼을 갖춘 목록으로 정리했다. 재생 화면의 어두운 배경을 유지하며 OS의 밝은 테마에서도 읽을 수 있다. 긴 문자열은 화면 안에서 줄바꿈한다.
- 빈 내용과 제어문자만 있는 내용은 등록하지 않는다. 작성 중 글자 수, 1000자 한도, 전송 상태, Ctrl/Cmd+Enter와 한글 조합 처리를 지원한다. 즉시 ref 잠금으로 같은 폼의 연속 제출을 막고 실패하면 입력을 보존한다. 성공한 응답을 검증한 뒤 목록에 반영한다.
- 로그인 링크는 현재 작품의 댓글 위치로 돌아온다. 댓글 비활성화 상태를 별도 표시한다. 로그인·인증·차단·요청 한도·수정 시간 초과 안내를 구분한다.
- 답글 작성과 접기/펼치기, 본인 댓글의 15분 내 수정 및 수정 표시, 삭제 확인, 운영자 삭제, 다른 댓글 신고를 기존 API에 연결했다. 부모 삭제 시 답글은 유지한다.
- 재생 페이지에서 버리던 최상위 nextCursor를 연결했다. 목록 요청 실패 시 기존 목록과 커서를 유지하고 같은 페이지를 재시도한다. 댓글 초기 조회 실패가 영상 재생을 막지 않으며 빈 댓글과 조회 오류를 구분한다.
- 답글 3개 미리보기 이후도 조회할 수 있다. 기존 GET `/api/episodes/:id/comments`에 선택적 `parentId`를 추가했다. 생략 시 기존 최신순 부모 스레드이며, 지정 시 해당 부모의 답글을 작성순으로 조회한다. 응답의 `{items, nextCursor}` 모양은 유지하고 OpenAPI에 쿼리를 기록했다. 새 DB 모델·마이그레이션은 없다.
- 답글 작성에서 숨김 부모 및 부모 작성자와의 차단 관계를 확인한다. 삭제된 부모를 숨김 답글만으로 보존하지 않는다. 조회는 공개된 상태의 삭제되지 않은 에피소드와 삭제되지 않은 시리즈에 한정한다.
- 사용자 조회를 저장보다 먼저 수행하여 사용자가 사라진 경우 댓글 등록/수정이 저장된 뒤 실패로 표시되는 경로를 제거했다. 답글 알림은 작품 소유자와 부모 작성자에게 중복 없이 전달하며 기존 자기 알림·차단 제외 규칙을 유지한다. 알림 실패는 저장 성공을 뒤집지 않는다.

## 검사

- 댓글 컴포넌트·스키마·서비스·조회 repository 및 기존 소셜 실패 격리 검사: 7개 파일, 33개 통과.
- 로컬 브라우저: 320·390·768·1440px에서 실제 컴포넌트의 등록→답글→수정→부모 삭제, 긴 본문 줄바꿈, 가로 넘침 없음 확인. 이 검사의 API 응답은 모의 응답이며 실제 DB 동작 검사와 구분한다.
- lint·TypeScript·dependency-cruiser·E2E 수집·Prettier 및 OpenAPI·오류 카탈로그 계약 검사 수행. O01 개발 Fast lane 적용, 전체 DB/Lighthouse 게이트 완료를 뜻하지 않는다.

## 운영 검증

배포 SHA·실행 결과는 아래에 최종 기록한다. 운영 QA는 별도 비공개 사용자·시리즈·에피소드에만 댓글을 만들고 끝나면 삭제한다. 실제 사용자의 댓글이나 작품 소유자에게 테스트 알림을 보내지 않는다.
