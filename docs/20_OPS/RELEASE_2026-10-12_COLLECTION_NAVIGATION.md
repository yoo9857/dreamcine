# 2026-10-12 — 실제 목록으로 이어지는 홈 탐색

- 홈의 동일 작품을 순서만 바꿔 로맨스·드라마·명작처럼 표시하던 선반을 인기·최신·롱폼·숏폼·영화제 큐레이션으로 정리한다. 인기/최신 피드는 병렬 조회하고, 숏폼 판정은 공통 workType·비율 기준을 따른다. 없는 분류는 숨긴다.
- “모두 보기”와 상단 탭·푸터는 검색어 없는 검색 또는 제목 키워드 검색 대신 실제 작품 목록의 정렬/형식 조건과 영화제 작가 프로필로 연결한다. 재생 페이지의 숏폼/롱폼 전체 보기도 형식을 유지한다.
- `/works?sort=popular|latest&format=long|short`를 지원한다. 서버 첫 페이지와 커서 API의 정렬을 일치시키고, 목록 형식은 새로고침·뒤로/앞으로 가기에 복원한다. 정렬을 바꿀 때 형식을 유지하고 목록 훅을 다시 초기화한다.
- 썸네일 없는 공개 작품을 홈에서 누락하지 않는다. 조회수가 없는 영화제 작품은 별도 큐레이션에 표시한다. 더 읽을 페이지가 남아 있으면 “숏폼 없음”을 성급하게 표시하지 않는다. 목록의 중첩 main을 제거한다.
- 비로그인 푸터의 “내 프로필”이 가짜 `/u/ilog`로 향하던 문제를 수정하고 로그인 후 계정 프로필로 연결한다. 공통 푸터 호출부에 실제 세션 유무를 전달한다.
