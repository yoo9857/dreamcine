# 시리즈 형식 드롭다운·AI 도구 선택·등록 화면 압축

사용자 요청: 누락된 등록 UX 점검, 카드형 시리즈 형식의 전문적인 드롭다운 전환, AI 도구 버튼과 직접 입력 병행, 긴 세로 레이아웃 개선.

## 구현

- 시리즈 형식은 네이티브 드롭다운으로 바꾸고 선택한 형식의 설명을 바로 표시한다. 키보드와 모바일 기본 선택 UI를 지원한다. 기존 여섯 형식과 서버 계약은 유지한다.
- 데스크톱 1360px 이상에서는 시리즈 선택·영상 정보·등록 요약을 가로로 배치한다. 영상 업로드와 준비 영상 선택도 같은 행을 사용한다. 작은 화면은 한 열이며 모바일 등록 버튼은 하단 내비게이션 위에 고정한다. 상담 버튼과 등록 버튼이 겹치지 않도록 위치를 조정했다.
- 시리즈 소개·기본 등급, 영상 설명·태그·등급, 상세 등록 요약은 펼쳐서 확인하는 선택 항목이다. 기본 입력부터 보이며 선택 항목의 DOM과 값은 유지된다.
- 좁은 등록 목록은 포스터·제목·선택 표시를 고정 격자로 배치한다. 제목·보조 정보는 한 줄 말줄임을 사용하고 제목 전체는 마우스 오버로 확인한다. 빈 시리즈의 중복 배지는 생략하고 보조 정보에 상태를 표시한다.
- AI 도구 11개를 여러 개 선택하는 버튼으로 표시한다. 목록에 없는 도구와 제작 설명은 직접 입력할 수 있고, 도구를 선택했다면 서술은 필수가 아니다. 선택을 취소해도 직접 쓴 내용은 보존한다.
- 선택한 도구와 설명은 기존 `aiDisclosure` 문자열에 `사용 도구: …` / `제작 설명: …`로 저장한다. 기존 자유 서술도 보존한다. 별도 `aiTools` 메타데이터를 쓰는 변경은 아니다. 모델·API·마이그레이션 추가는 없다. 합계 500자 초과 시 입력을 자르지 않고 안내한다.
- 등록 위치를 바꿀 때 새 시리즈 초안과 형식이 사라지던 부분을 고쳤다. 시리즈 생성과 영상 저장 중 등록 대상 변경을 잠그고, 저장 중인 상세 입력도 보호한다. 영상 업로드 컴포넌트는 유지한다.
- 시리즈 공백 제목 검증, 성공 응답 검증, 세션 만료 등 서버 오류 안내를 추가했다. 실패 시 입력을 유지하고 오류 안내로 초점을 이동한다. 초안 저장 성공 후 완료 제목으로 초점을 이동한다. 사용 자산은 제출 중 UI 상태 대신 응답의 assetId로 목록에서 제거한다. 저장 완료 요약의 등급은 실제 저장 값을 표시한다.

## 검증

- 관련 컴포넌트 Vitest 41개 통과. 도구 선택/취소, 서술 없는 등록 준비, 기존 자유 입력 보존, 500자 초과 시 보존, 드롭다운 연동, 위치 전환 시 초안 유지, 저장 중 잠금/실패 복원, 잘못된 응답 및 서버 오류를 포함한다.
- 로컬 실제 컴포넌트 브라우저: 320·390·768·1024·1366·1440px. 여섯 형식 전환, Home/ArrowDown 키보드 선택, 초안 유지, AI 복수 선택과 직접 입력, 모바일 등록 버튼의 화면 내 위치, 가로 넘침·페이지 오류 없음 확인. 데스크톱·모바일 스크린샷으로 배치를 확인했다.
- 임시 로컬 미리보기 라우트는 검사 후 삭제한다. 인증 경계를 바꾸지 않는다. 업로드·트랜스코딩 파이프라인은 변경하지 않았다.
- O01 Fast lane의 관련 테스트·정적 검사 및 웹만 배포를 적용한다. 전체 CI·성능 게이트 완료를 뜻하지 않는다. 배포 SHA와 운영 검증 결과는 `docs/HANDOFF.md`에 최종 기록한다.
