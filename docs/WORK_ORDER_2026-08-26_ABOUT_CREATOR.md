# 작업지시서 — About 및 크리에이터 모집

작성일: 2026-08-26
상태: 구현·검증 완료, 운영 배포 대상

## 라우트 소유권

- `/`: 유일한 공개 랜딩 페이지. 별도 랜딩을 추가하지 않는다.
- `/about`: ilog의 브랜드 소개와 세계관을 담당한다.
- `/creator-apply`: 모집 분야·절차·지원서 접수만 담당한다.
- `POST /api/creator-applications`: 지원서를 검증하고 저장한다.

## 완료 범위

- `/about`에 인물·작품 이미지 레일, 포인터 깊이 반응, 스크롤 리빌,
  번호형 편집 섹션, 마키, 와이어프레임 인물 보드, 작품 프레임 보드와 CTA를 구현했다.
- 공개 발언을 소개하는 업계 인물은 ilog 참여자나 파트너로 오인되지 않도록 고지했다.
- `/creator-apply`에서는 About과 중복되던 인물 레일·입자·브랜드 서사를 제거했다.
- 지원서는 Prisma 모델·마이그레이션·검증 스키마·저장소·서비스·API로 연결했다.
- 동일 이메일과 모집 라운드의 재제출은 새 행을 만들지 않고 갱신한다.
- 공개 랜딩 푸터에서 About과 크리에이터 모집으로 연결했다.

## 다음 작업 지시

1. About의 인물·작품 이미지를 교체할 때 카드 비율과 로컬 최적화 경로를 유지한다.
2. 공개 발언의 인물은 협업 관계처럼 표현하지 말고 출처·고지를 유지한다.
3. 모집 라운드를 변경할 때 `CREATOR_APPLICATION_ROUND`와 운영 문구를 함께 변경한다.
4. 관리자 지원서 목록·상태 변경 화면은 별도 권한 보호 라우트로 구현한다.
5. `/about` 또는 `/creator-apply`를 새로운 랜딩 페이지로 복제하지 않는다.

## 검증 기록

- 데스크톱 1440×1000, 모바일 390×844 브라우저 검수 완료
- 레일 애니메이션, 스크롤 리빌, 작품 카드 진입 동작 확인
- 두 화면 모두 가로 오버플로와 브라우저 콘솔 오류 없음

  Prettier 검사
